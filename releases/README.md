# Android test APKs

These APKs are built against the live NilePay API at `https://nilepay-api.runasp.net`.

- `nilepay-detector-live-debug.apk` is the merchant detector application.
- `nilepay-admin-live-debug.apk` is the administrator application.

They are debug-signed builds intended for installation and live-service testing. They must not be distributed as production releases. Production packages require the private release signing key and a separately signed release build.
